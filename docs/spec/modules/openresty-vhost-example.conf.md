## 1. Overview & Architectural Role

`openresty-vhost-example.conf` provides the reference OpenResty / Nginx virtual host configuration.
It defines:
1. Static asset routing and caching headers for shipped frontend assets.
2. Reverse proxy forwarding to upstream `go-music-dl` (`127.0.0.1:9981`).
3. Upstream gzip disabling (`proxy_set_header Accept-Encoding ""`) to enable plain-text DOM filtering.
4. `sub_filter` HTML injection template injecting theme stylesheets, pre-hydration script, and deferred JS modules before `</head>`.
5. Cache-busting version parameters (`?v=<hash>`), maintained reversibly by `deploy.sh`.

---

## 2. Configuration Directives Specification

### 2.1 Static Asset Locations
Static assets are served directly from web root with a 1-hour cache expiry:
```nginx
location = /gmdl-dark.css {
    root /usr/share/nginx/html;
    default_type text/css;
    expires 1h;
}

location = /gmdl-ui.js {
    root /usr/share/nginx/html;
    default_type application/javascript;
    expires 1h;
}

location = /gmdl-feat.js {
    root /usr/share/nginx/html;
    default_type application/javascript;
    expires 1h;
}
```

### 2.2 Dynamic App Proxy & sub_filter Injection
HTML responses from upstream are uncompressed, never cached (`expires -1`), and injected:
```nginx
location / {
    proxy_pass http://127.0.0.1:9981;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_redirect http://127.0.0.1:9981/ /;

    # Dynamic app: never cache HTML/API
    expires -1;

    # Disable upstream gzip so sub_filter can match string in plain HTML
    proxy_set_header Accept-Encoding "";

    # Injection before </head>
    sub_filter "</head>" "<link rel=\"stylesheet\" href=\"/gmdl-dark.css?v=__CSS_VER__\"><script>(function(){try{var u=JSON.parse(localStorage.getItem('gmdl-ui')||'null');var t=u&&u.theme;if(!t||t==='auto'){t=(window.matchMedia&&matchMedia('(prefers-color-scheme: light)').matches)?'light':'dark';}if(t==='dark'){document.documentElement.classList.add('dark');}}catch(e){try{document.documentElement.classList.add('dark');}catch(_){}}})();</script><script src=\"/gmdl-ui.js?v=__UI_VER__\" defer></script><script src=\"/gmdl-feat.js?v=__FEAT_VER__\" defer></script></head>";
    sub_filter_once on;
}
```

## 3. Maintenance Interface for `deploy.sh`

- The `sub_filter` line contains three version parameters:
  - `gmdl-dark.css?v=<hash>`
  - `gmdl-ui.js?v=<hash>`
  - `gmdl-feat.js?v=<hash>`
- `deploy.sh` matches these version patterns and replaces them with computed SHA-256 asset hashes.
- Pattern matching must be exact and preserve the surrounding inline script verbatim.

## 4. Observable Acceptance Criteria

- **AC-CONF-01:** Static asset locations for `gmdl-dark.css`, `gmdl-ui.js`, and `gmdl-feat.js` include `expires 1h`.
- **AC-CONF-02:** Location `/` sets `expires -1` and `proxy_set_header Accept-Encoding ""`.
- **AC-CONF-03:** Injected pre-hydration script safely handles uninitialized or corrupt `localStorage['gmdl-ui']`.
- **AC-CONF-04:** Query string format adheres to `?v=<hash>` matching the format generated by `deploy.sh`.
- **AC-CONF-05:** Config passes `nginx -t` validation in an environment where nginx is installed (marked **currently BLOCKED/UNVERIFIED** in sandbox).
